# Network Packet Sniffer

This project captures and analyzes network packets using Python and Scapy. 
It was developed as part of my **CodeAlpha Cyber Security Internship**.

## Features
- Capture live network packets
- Display source/destination IPs, protocols, and payload previews
- Save captured packets into `.pcap` files
- Recognizes known hosts like Google DNS and Cloudflare DNS

sudo python3 task1.py
